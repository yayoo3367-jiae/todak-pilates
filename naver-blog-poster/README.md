# naver-blog-poster

네이버 블로그에 글을 자동으로 게시하는 도구입니다. 네이버는 외부에서 글쓰기가 가능한
공식 오픈 API를 더 이상 제공하지 않기 때문에(과거 블로그 API의 글쓰기 기능은 폐지됨),
이 도구는 Playwright로 실제 브라우저를 열어 스마트에디터를 조작하는 방식으로 동작합니다.

## ⚠️ 사용 전 꼭 확인하세요

- **본인이 소유한 블로그 계정에만 사용하세요.** 아이디/비밀번호를 코드에 저장하지 않고,
  로그인은 직접 브라우저 창에서 수동으로 진행한 뒤 로그인 세션만 재사용합니다.
- 네이버 이용약관상 비정상적인 자동 접속/게시가 제한될 수 있습니다. 짧은 간격으로
  대량 게시하거나 스팸성으로 사용하지 마세요. 사람이 쓰는 것과 비슷한 빈도로 사용하는 것을 권장합니다.
- 네이버가 에디터 화면 구조(HTML)를 변경하면 자동화 선택자가 깨질 수 있습니다.
  이 경우 `HEADLESS=false`로 실행해 어디서 멈추는지 확인 후 `src/post.js`의 선택자를 조정해주세요.
- `auth/` 폴더에는 로그인 세션(쿠키)이 저장됩니다. 개인정보이므로 절대 커밋하거나
  공유하지 마세요 (`.gitignore`에 이미 제외되어 있습니다).

## 설치

```bash
cd naver-blog-poster
npm install
npx playwright install chromium
cp .env.example .env
# .env 파일을 열어 NAVER_BLOG_ID 값을 본인 블로그 아이디로 수정
```

## 사용법

### 1. 최초 1회 로그인

브라우저 창이 뜨면 직접 로그인하고, 로그인 완료 후 터미널로 돌아와 Enter를 누릅니다.
로그인 세션이 `auth/naver-storage.json`에 저장되며, 이후에는 다시 로그인할 필요가 없습니다
(세션이 만료되면 다시 실행하면 됩니다).

```bash
npm run login
```

### 2. 게시할 글 작성

`content/` 폴더에 아래 형식으로 글 파일을 작성합니다 (`content/example-post.md` 참고).

```
title: 글 제목
tags: 태그1, 태그2
category: 카테고리명
---
첫 번째 문단입니다.

두 번째 문단입니다.
![사진 설명](./content/images/photo.jpg)

이미지 아래 마지막 문단입니다.
```

- `title` / `tags` / `category`는 선택 사항입니다. 생략하면 첫 줄이 제목이 되고,
  기본 카테고리로 게시됩니다.
- 이미지는 `![설명](로컬경로)` 형식으로 문단 자리에 넣으면 자동 업로드됩니다.

### 3. 게시 실행

먼저 실제로 게시하지 않고 내용만 확인하려면:

```bash
npm run post -- --file content/example-post.md --dry-run
```

문제가 없으면 실제로 게시합니다:

```bash
npm run post -- --file content/example-post.md
```

브라우저 동작을 눈으로 보고 싶다면 `.env`에서 `HEADLESS=false`로 바꾼 뒤 실행하세요.

## 예약 발행 / 정기 게시

이 스크립트는 실행하면 즉시 1회 게시합니다. 매일/매주 정해진 시간에 자동으로 올리고
싶다면, 서버나 로컬 PC의 cron(macOS/Linux) 또는 작업 스케줄러(Windows)에
`npm run post -- --file content/오늘의글.md` 명령을 등록해 사용하세요.

## 문제 해결

- **로그인 세션이 자꾸 만료돼요**: 네이버가 새 기기/브라우저에서의 로그인을 의심 활동으로
  판단해 재인증을 요구할 수 있습니다. `npm run login`을 다시 실행해주세요.
- **선택자를 못 찾는다는 오류가 나요**: `auth/last-error.png`에 오류 시점 스크린샷이
  저장됩니다. 이를 참고해 `src/post.js`의 CSS 선택자를 최신 에디터 구조에 맞게 수정하세요.
