# 토닥 필라테스 주간 보고

원장님이 덧붙인 메모: $ARGUMENTS

## 기간
- 한국 시간 기준 **이번 주 월요일부터 오늘까지**예요.
- 오늘이 월요일이면 지난주 월요일부터 일요일까지로 잡아요.
- 먼저 `TZ=Asia/Seoul date`로 오늘 날짜를 확인하고, 보고서 맨 위에 기간을 적어요.

## 1. 자료 모으기
아래 자료를 쓸 수 있는 만큼 찾아요. 연결되어 있지 않은 도구는 건너뛰어요.
- **원장님 메모:** 위에 붙인 메모가 가장 정확한 자료예요. 메모와 다른 자료가 서로 다르면 메모를 따라요.
- **저장소 작업:** `git log --since="<이번 주 월요일> 00:00" --pretty="%ad %s" --date=short --all`와 이번 주에 바뀐 파일을 봐요. 랜딩페이지, 판매 페이지, 진단 페이지, 대본, 블로그 글 같은 작업이 여기에 나와요.
- **SNS 발행·반응:** uplika가 연결되어 있으면 이번 주 게시물(list_posts)과 반응(get_insights)을 봐요.
- **광고·채널 수치:** Windsor.ai가 연결되어 있으면 이번 주 유튜브·인스타그램 지표를 봐요.
- **기록 문서:** Notion이나 Google Drive가 연결되어 있으면 이번 주 수업 기록, 상담, 매출 문서를 찾아봐요.

**지어내지 않아요.** 찾지 못한 숫자나 사실은 "자료 없음"이라고 적어요. 특히 매출과 수업 숫자는 추측하지 않아요.

## 2. 보고서 형식
아래 형식 그대로 써요. 문장은 짧게, 다정하지만 군더더기 없이 써요.

```
# 주간 보고 · YYYY.MM.DD(월) ~ MM.DD(요일)

## 한눈에 보기
- (이번 주 가장 중요한 일 3가지 이내, 한 줄씩)

## 1. 수업
| 항목 | 이번 주 | 메모 |
| --- | --- | --- |
| 수업 횟수 (개인·그룹) | | |
| 신규 상담 / 등록 | | |
| 회원 변화·후기 | | |

## 2. 마케팅
| 채널 | 한 일 | 반응·수치 |
| --- | --- | --- |
(네이버 블로그, 인스타그램, 플레이스, 광고, 오프라인 등 이번 주에 한 채널만)

## 3. 콘텐츠
| 콘텐츠 | 상태 (기획·촬영·편집·발행) | 메모 |
| --- | --- | --- |
(유튜브, 릴스, 자세교정 영상 상품, 대본, 페이지 작업 등)

## 4. 매출
| 항목 | 금액 | 메모 |
| --- | --- | --- |
| 수업 매출 | | |
| 영상·온라인 매출 | | |
| 합계 | | |

## 5. 다음 주 할 일
- [ ] (우선순위 순서로 5개 이내. 메모와 자료에서 나온 일을 먼저 쓰고, 제가 제안한 일에는 끝에 "(제안)"을 붙여요)

## 채워 주시면 좋은 자료
- (이번 보고서에서 "자료 없음"이었던 항목을 한 줄씩. 없으면 이 칸은 빼요)
```

- 해당하는 자료가 하나도 없는 칸은 표를 지우지 말고 "자료 없음"으로 남겨요.
- 각 칸에는 어디서 나온 자료인지 짧게 적어요. 예: (메모), (git), (uplika).

## 3. 저장
- 완성한 보고서를 `reports/주간보고-YYYY-MM-DD.md`(오늘 날짜)에 저장해요.
- 대화창에는 보고서 전체를 보여 주고, 마지막 줄에 저장한 파일 위치를 알려 드려요.
- 커밋이나 푸시는 원장님이 부탁하실 때만 해요.
