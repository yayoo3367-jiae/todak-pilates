# 토닥필라 웹사이트

## 이 저장소(폴더)에 있는 파일들

- **`index.html`** — 홈페이지예요. 사이트 주소로 들어오면 가장 먼저 보이는 페이지입니다.
- **`landing.html`** — "8주 프로그램" 소개 페이지예요. 홈페이지의 "8주 프로그램 알아보기" 버튼을 누르면 이 페이지로 이동합니다.
- **`assets/images/`** — landing.html에 들어가는 사진들이 저장된 폴더예요. (원래 사진이 너무 커서 용량을 줄여 저장했어요.)
- **`archive/`** — 지금은 사용하지 않는 예전 페이지들을 모아둔 폴더예요. (자세한 내용은 아래 참고)
- 이 파일 (`README.md`) — 지금 읽고 계신 안내문이에요.

## GitHub Pages로 사이트 열기 (무료로 웹사이트 주소 만들기)

1. GitHub 저장소 페이지에서 **Settings(설정)** 탭을 클릭해요.
2. 왼쪽 메뉴에서 **Pages**를 클릭해요.
3. **Source(소스)** 항목에서 **Deploy from a branch**를 선택해요.
4. 브랜치는 지금 작업 중인 브랜치를 선택하고, 폴더는 **`/ (root)`**를 선택해요.
5. **Save(저장)** 버튼을 눌러요.
6. 1~2분 정도 기다리면 같은 페이지에 사이트 주소(URL)가 나타나요. 그 주소가 우리 사이트의 실제 링크예요. 네이버 플레이스나 인스타그램 프로필에 이 링크를 걸어두시면 돼요.

## `archive/` 폴더에 대해

`archive/` 폴더 안에 있는 파일들은 지금 사용하지 않는 예전 페이지 초안들이에요. 나중에 참고용으로 남겨둔 것이고, 실제 사이트(index.html, landing.html)에는 연결되어 있지 않아요. 삭제하지 않고 그냥 보관만 해둔 것이니 신경 쓰지 않으셔도 됩니다.
